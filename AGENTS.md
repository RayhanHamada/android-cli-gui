# android-cli-gui

Unofficial GUI for the Android CLI (https://developer.android.com/tools/agents/android-cli): manage SDK packages, devices, and related tooling without installing Android Studio.

Source of truth: all data comes from official Android sources and documentation, or from the CLI itself.

## Agent skills

### Issue tracker

Issues live in GitHub Issues (`RayhanHamada/android-cli-gui`) and are managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels, unchanged: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` plus `docs/adr/`. See `docs/agents/domain.md`.
